# 调研底稿：Workbuddy 功能模型（专家中心 / 知识库集成 / 人机双写）

- 日期：2026-09-11（页面抓取核验）
- 用途：模块 01（专家与专家团）、模块 02（团队协作）、模块 05（知识库）的 PRD 对标依据
- 来源：workbuddy.cn 官方文档（Expert-Center / IMA Knowledge Base / Lexiang / Cowriting 四页）

## 1. 专家中心（Expert Center）

- **专家 = 「角色切换」机制**：以「人设 + 方法论 + 工具链」让产品以特定领域专家身份执行任务。
- **专家团 = 「协作执行」机制**：多位专家分工协作，由**团长**自动拆解、并行执行并整合交付。
- 三层选型逻辑：「Skill 是能力；专家是能力+经验；专家团是多位专家+协作流程」。
- 板块结构：**专家中心**（内置专家/专家团，按行业分类浏览，「召唤」进入对话）+ **我的专家**（用户创建，分享专业知识）。
- 卡片：能力介绍/擅长领域/任务示例；专家团卡额外展示团队成员。
- 对话内切换：专家下拉（搜索 + 置顶，结果持久）；**专家团会话独占**——切换其他专家需开新对话。
- 成本锚点：专家团消耗通常为单专家 **3–5 倍**积分（并行多专家多轮）。
- 安全声明：专家本身不主动获取系统权限，仅处理对话与上传文件；配备 Skill/MCP 时才在授权下间接访问；信息收集表（账户/对话必要，上传文件与工作区文件非必要）；医疗/法律/投资免责。

## 2. 知识库集成（IMA / 乐享）

- 集成模式均为「**资料库连接器 + 用户级 OAuth 授权**」（企业统一身份或微信扫码），非 MCP、非 API Key 配置；权限继承自登录用户。
- IMA：企业版连接器（iOA 账号环境，统一管理不可解绑）与个人版（微信扫码，可解绑）双连接器，授权范围=查看库列表/检索/文件入任务与产物回写。
- 乐享：个人级 OAuth（读库/搜索查询/创建编辑内容三项授权）；浏览层级「团队空间 → 知识库 → 文件」。
- 体验深度：止步于「知识库文件作为任务上下文附加」+「产物上传到云端」；**无回答内引用/溯源标注**（LaboFlow 模块 05 的引用卡是差异化点）。

## 3. 人机双写（Cowriting，右侧文件预览区 AI 协作编辑）

- 支持品类：Word / Excel / PPT / Markdown / 腾讯文档（腾讯文档提供底层技术）；本地与云端沙箱行为一致。
- 实际审阅模型：**选中 → 评论框引用选区 → AI 原地应用修改 → 淡黄色高亮改动 → 撤销/重做**。该页**没有** accept/reject 修订建议流与 diff 对照——「修订建议」模式出自其资料库 MD 文档功能（模块 02 的需求来源），两者不是一回事。
- PPT 品类能力最强（竞品重点）：选页编辑、多选元素批量指令、画布自由框选（生成结果落在指定位置）、选中基准页刷新整份风格；四种选中方式（元素点选/框选/目录缩略图左上角/缩略图右键）。
- 成本模型：手动编辑不耗积分；AI 编辑耗积分；选区精调比全文描述省 Token。
- 边界：仅操作用户主动打开的文档；改动可核对、可撤销。

## 4. 对 LaboFlow 的启示

1. 专家体系是「角色封装」而非编排面板——产品呈现按「召唤」叙事，编排复杂度藏在后面。
2. 知识库走开放标准（MCP）+ 引用溯源，是对 Workbuddy 私有连接器模式的差异化。
3. 「修订建议 accept/reject」在 Workbuddy 的资料库中已有、在人机双写中没有——LaboFlow 模块 02 做全「评论+修订建议+按评论修订」链路即可对齐其最强形态。
