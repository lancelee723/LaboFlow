## 1. 背景与定位

### 1.1 业务背景

咨询团队在项目过程中积累大量文件：客户内部资料（财务报告/工作总结/规章制度/业务资料）、行业数据（表格或数据库）、案例资料、政策法规——多为 Office/PDF 格式。这些资料需要被检索、被引用进分析，同时**保密要求极高**（客户 NDA）：资料统一管理、数据边界清晰是第一原则。

### 1.2 方案定位（用户裁决的架构）

**不做**「知识库与桌面端整合」（工程量过大、不利于资料统一管理与保密）；**做**「外部知识库接入」：

1. **MCP 通道（AI 检索）**：用户/组织自行部署 [WeKnora](https://github.com/Tencent/WeKnora)（腾讯开源，MIT 许可，Docker Compose/K8s 部署，无需 GPU；官方 MCP 服务器 `tencent-weknora-mcp` 提供 `hybrid_search` 等约 29 个工具）；LaboFlow 以标准 MCP 客户端接入——**体验与当前网页版 LaboFlow 类似**，但组织用户可接受组织统一下发的 MCP 服务器地址与 API Key，无需自行配置。
2. **内嵌浏览器通道（人工浏览）**：侧栏/工作区新增「知识库」图标，打开部署好的 WeKnora 网页端，浏览、下载文件。本质是内嵌浏览器访问特定 URL（组织下发或用户自填）——**平台自由**：用户没选 WeKnora 而是其它知识库平台（Confluence/语雀/SharePoint/自建门户），一样打开。

### 1.3 与竞品的差异

Workbuddy × IMA/乐享是「连接器 + OAuth 授权」私有集成（权限随用户账号传递，但无回答内引用溯源）；LaboFlow 走**开放 MCP 标准**：不绑定任何知识库厂商，组织可私有部署（保密可控），且**检索结果带引用标注**（超出竞品当前体验）。

## 2. 用户与场景

### 2.1 目标用户

| 画像 | 诉求 |
|---|---|
| 顾问 | 任务里让 Agent 检索知识库（客户资料/行业数据），回答带来源；随时翻知识库网页端查文件、下载 |
| 组织管理员/IT | 统一部署 WeKnora、统一下发 MCP 配置与 Key；成员零配置 |
| 个人用户（无组织） | 自己部署或使用任意知识库平台：自填 MCP 配置或网页 URL |

### 2.2 核心用户故事

- US-KB01 作为顾问，我在任务里输入「基于知识库里的客户A年报，梳理近三年收入结构」，Agent 经 WeKnora MCP 检索并给出带引用的回答。
- US-KB02 作为组织成员，IT 部署好 WeKnora 后我登录组织，知识库 MCP 自动出现（带「组织」标记），我没填过任何配置。
- US-KB03 作为顾问，我点侧栏「知识库」图标，内嵌浏览器打开我们公司的 WeKnora 网页端，找到一份行业报告下载到本地并拖进会话。
- US-KB04 作为个人用户，我不用 WeKnora 而用公司 Confluence——我在设置里自填 Confluence 的 URL，「知识库」图标打开它；若它有 MCP 服务，我也可手动登记检索工具。
- US-KB05 作为组织管理员，我在管理台配置知识库下发项（名称/URL/API Key/说明），可随时停用。

## 3. 功能需求

### 3.1 知识库 MCP 通道（AI 检索）

- **FR-KB-01（M）** 个人自配：设置 → 知识库 tab 新增「检索服务（MCP）」：登记 MCP 服务器（名称/传输 stdio|http/url/凭证），复用既有用户 MCP 机制；新增**连接测试**（listTools 探活 + 工具清单回显）。
- **FR-KB-02（M）** 组织下发：登录组织后自动接收 `kbServers[]`（名称/URL/API Key 引用/说明），注册为知识库检索服务（「组织」标记，只读不可删，登出后停用）；**无需用户自行配置**。下发项落**既有 MCP 注册表**（`mcp_servers` 加 `source=org` 标记，组织条目不占个人 16 上限；不建平行注册表——裁决 R5-10，见 SPEC §2.1）。
- **FR-KB-03（M）** WeKnora 一键引导：知识库 tab 提供「WeKnora 部署与接入指引」（官方 docker compose 命令、API Key 获取路径、MCP 配置样例——`tencent-weknora-mcp` 的 HTTP 传输 + `X-API-Key` header 形态直接可抄）。
- **FR-KB-04（M）** 检索引用体验：会话中调用知识库检索工具的结果以**引用卡**呈现（来源知识库/文档名/片段预览/相关性分），Agent 回答中的事实陈述可关联引用（提示词契约 + 工具结果结构化）；引用卡可跳转（有 URL 时打开网页端对应位置，联动内嵌浏览器）。
- **FR-KB-05（S））** 知识库工具选择：多检索服务并存时，会话可指定用哪个（或 Agent 按名称路由）；权限模式沿用既有 MCP 工具审批。

### 3.2 知识库网页端通道（内嵌浏览器）

- **FR-KB-06（M）** 侧栏/工作区左栏「知识库」入口：打开内嵌浏览器面板（复用既有 browser-view/WebContentsView），加载**当前知识库 URL**（组织下发优先，个人可自填覆盖/新增多个）。
- **FR-KB-07（M）** 浏览体验：地址栏（仅展示+可跳转白名单内地址）、前进/后退/刷新、多标签（多个知识库/多个页面）、独立持久 session（登录态保留，partition 独立于工作浏览器）。
- **FR-KB-08（M）** 下载落地：网页端下载的文件拦截 → 保存对话框（默认项目目录/下载目录）→ 「带入会话」快捷动作（作为附件进入当前会话）。
- **FR-KB-09（S）** 组织下发 URL 与个人 URL 并存（列表切换）；企业代理/内网环境遵循既有网络代理设置。

### 3.3 组织管理（服务端）

- **FR-KB-10（M）** 管理台「知识库」配置：下发项 CRUD（类型：MCP 服务 / 网页 URL；名称/地址/凭证（MCP Key 加密存储）/说明/启用开关）；下发即达（成员下次 bootstrap 生效）。
- **FR-KB-11（S）** 下发项可用范围（全员/指定团队）。

### 3.4 横切

- **FR-KB-12（M）** 安全：API Key 加密存储（服务端加密下发、客户端 host secrets 落地，UI 不回显）；非环回 HTTP MCP 沿用 ADR-0142 确认流；知识库网页域不做深度注入（只浏览不操控）。
- **FR-KB-13（M）** i18n 8 语言。
- **FR-KB-14（S）** 检索用量可见：知识库工具调用次数/tokens 进用量页维度。

## 4. 范围裁决（明确不做）

| 事项 | 裁决 |
|---|---|
| 知识库引擎进桌面端（本地索引/向量库） | 不做（R5-3）：保密与统一管理优先，用户/组织自部署 |
| 文档向知识库的回写（产物存入 WeKnora） | v1 不做：网页端手动上传已覆盖（内嵌浏览器可达）；MCP 写工具（create_knowledge_from_file 等）开放为 Agent 可用能力（有权限审批），但不做专门「上传到知识库」按钮 |
| 对特定厂商（IMA/乐享式）OAuth 连接器 | 不做：开放 MCP + 内嵌浏览器已覆盖任意平台 |
| 网页端内嵌深度操控（自动点击/表单） | 不做：内嵌浏览器仅浏览+下载（与 pi.browser 工作浏览器区隔） |

## 5. 非功能需求

| # | 需求 |
|---|---|
| NFR-KB1 | 连接：MCP 探活 ≤5s（失败可读分诊断：网络/鉴权/服务不兼容）；断线重连沿用既有 MCP 状态机 |
| NFR-KB2 | 内嵌浏览器：独立 partition（`persist:kb-browser`），与工作浏览器 cookies/缓存隔离；崩溃不影响主窗口（WebContentsView 宿主隔离） |
| NFR-KB3 | 凭证安全：组织下发的 API Key 全链路密文（服务端加密存储 → TLS → 客户端 secrets），审计可查下发/停用事件 |
| NFR-KB4 | 并发：检索工具调用结果 ≤4000 字符截断沿用既有 MCP 行为；引用卡渲染 50 条内虚拟滚动 |

## 6. 里程碑与验收

| 里程碑 | 内容 | 验收 |
|---|---|---|
| M-KB1 | 知识库 tab（个人自配 + 连接测试 + WeKnora 指引）+ 引用卡体验 | FR-KB-01/03/04；自部署 WeKnora 实测检索带引用 |
| M-KB2 | 组织下发（服务端 + 客户端）+ 内嵌浏览器面板 | FR-KB-02/06~08/10~12；成员登录零配置可用；下载带入会话 |
| M-KB3 | 打磨（多库路由/用量/范围） | FR-KB-05/09/11/14；Gate KB |

**Gate KB（模块出口）**：全部 M 级验收；真实 WeKnora（docker compose 部署）端到端：上传 3 类文件（PDF/Word/Excel）→ 会话检索带引用 → 网页端浏览下载 → 带入会话；组织下发/停用链路 E2E；安全自查（Key 链路/隔离/代理）通过。

## 7. 名词术语

| 术语 | 定义 |
|---|---|
| WeKnora | 腾讯开源 LLM 知识库平台（Go + Vue，MIT），多租户 RBAC，13 种文档格式，REST + 官方 MCP 服务器 |
| 知识库检索服务 | 登记在 LaboFlow 的 MCP 形态检索能力（个人自配或组织下发），提供 hybrid_search 等工具 |
| 引用卡 | 检索结果的结构化呈现：来源库/文档/片段/分数，可跳转 |
| 下发项 | 组织管理台配置、经 bootstrap 下发的知识库配置（MCP 服务或网页 URL） |
