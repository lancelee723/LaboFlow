## 1. 背景与定位

### 1.1 业务背景

「手机远程指挥」（模块 03）需要真实的 IM 渠道承载。用户指定三种主流平台：**微信 bot、企业微信机器人、飞书机器人**。本模块是通道基础设施供给方：向助理模式（模块 03）提供统一的「收消息→派任务→回结果」通道能力。

### 1.2 平台可行性结论（2026-09 官方文档核验，关键裁决依据）

| 平台 | 官方路线 | 免公网 | 文件 | 回复窗口 | 结论 |
|---|---|---|---|---|---|
| **飞书** | 企业自建应用 + **WebSocket 长连接** | ✅（官方明确「无需公网 IP/内网穿透」） | ✅ ≤30MB | 无硬窗口（5 QPS/用户） | **首选首发**，工程风险最低 |
| **企业微信** | **智能机器人**（API 模式，WSS 长连接 `wss://openws.work.weixin.qq.com`） | ✅（BotID+Secret 长连接） | ✅ ≤20MB（3 天有效期） | 24h（流式回复 10min 内） | 次发；自建应用回调路线需公网，列为备选 |
| **微信** | **公众号**（认证服务号 + 客服消息 API） | ❌ 需公网回调 → **经 LaboFlow Server 中继**（组织部署天然可用；个人需测试号/自备穿透） | 图文/素材为主 | 48h 内 5 条（被动回复 5s） | 第三发；**无官方个人号 bot API，明确不走非官方协议**（R5-5） |

> 微信通道的诚实说明（写进产品文档）：微信官方未开放个人号机器人收发 API；本产品采用**公众号**官方路线——组织客户经服务端中继即可用；个人用户可申请**测试号**体验完整链路。任何 Wechaty/协议号方案因封号与合规风险明确不做。

### 1.3 通用通道抽象

三通道共用统一 `ChannelAdapter` 接口（连接/收消息/发消息/发文件/状态），未来 QQ（官方 bot WSS）、钉钉（Stream 模式）、企业微信群机器人（仅推送）可按同一接口扩展（C 级）。

## 2. 用户与场景

### 2.1 核心用户故事

- US-IM01 作为顾问，我在设置 → 助理设置 → 飞书卡片里粘贴 app_id/app_secret，点连接：状态灯变绿，手机上私聊机器人发一句话，电脑上的 LaboFlow 开始执行并回复。
- US-IM02 作为顾问，我在企业微信管理后台创建智能机器人（API 模式），把 BotID/Secret 粘进卡片，群里 @机器人 下任务，流式回复逐步刷出。
- US-IM03 作为组织管理员，我在管理台配置公众号中继（填公众号凭证），成员客户端零配置获得微信通道。
- US-IM04 作为顾问，任务产出的 PPT 直接以文件消息发回我的飞书/企微。
- US-IM05 作为顾问，凭证填错时卡片明确告诉我错在哪（token 无效/权限缺失/应用未发布），而不是笼统的「连接失败」。

## 3. 功能需求

### 3.1 通道配置体验（三通道一致的 UI）

- **FR-IM-01（M）** 设置新增「助理」tab（助理设置）：通道卡片列表——每卡含：通道名/图标、连接状态灯（未连接/连接中/已连接/错误+原因）、配置表单、连接/断开按钮、使用说明链接（各平台开放平台配置指引，含所需权限清单与发布步骤）。
- **FR-IM-02（M）** 凭证管理：粘贴式录入（飞书 app_id+app_secret / 企微 BotID+Secret / 公众号 appid+secret+Token+EncodingAESKey）；**整卡保存、空值视为「未修改」**（绝不因空输入冲掉已存凭证）；「粘贴一段自动识别」多行凭证文本（从开放平台凭证页整页复制也能解析出字段）；凭证存 host secrets，界面永不回显明文。
- **FR-IM-03（M）** 连接体检：主动连通性检查并给出**分诊断**（网络不可达 / 凭证无效 / 权限缺失（列缺的 scope）/ 应用未发布或不可用范围问题），按平台错误码映射为可读中文。
- **FR-IM-04（S）** 每通道可配：生效范围（私聊/群聊@/两者）、白名单（限定可下指令的用户/群，默认仅本人——按平台身份标识 open_id/userid）。

### 3.2 飞书通道

- **FR-IM-05（M）** 企业自建应用 + WebSocket 长连接：接收 `im.message.receive_v1`（私聊 + 群@）；回复用 `im/v1/messages`（文本/post 富文本/interactive 卡片）；文件回传先上传（图片 ≤10MB / 文件 ≤30MB → image_key/file_key）。
- **FR-IM-06（M）** 可靠性：按 `message_id` 去重（平台会重推）；事件 3s 内 ACK（先 ACK 后异步处理）；断线指数退避重连；连接数 ≤50 限制内单连接。
- **FR-IM-07（S）** 富体验：回复卡片（任务标题/状态/耗时/token），长回复折叠「展开全文」；流式更新卡片（卡片 patches）。

### 3.3 企业微信通道

- **FR-IM-08（M）** 智能机器人（API 模式）+ WSS 长连接：收文本/引用消息（单聊 + 群@机器人）；回复支持 `markdown`（≤20480B）与 `template_card`；文件分片上传（≤20MB）。
- **FR-IM-09（M）** 流式回复：执行中任务按 `stream` 分块推送（10min 内完成），完成后发终稿；24h 回复窗口内自由回复。
- **FR-IM-10（C）** 自建应用路线（备选，需公网）：服务端中继回调 + 应用消息 API（text/markdown/file）。

### 3.4 微信公众号通道（经服务端中继）

- **FR-IM-11（M）** 服务端中继：管理台配置公众号凭证；`POST /bots/webhook/wechat` 接收微信回调（URL/Token/EncodingAESKey 验签解密）→ 按 bot 绑定路由到对应桌面客户端（WS 下发）→ 客户端执行后经客服消息 API 回复。
- **FR-IM-12（M）** 回复语义适配：被动回复 5s 内无法完成长任务 → 先回「任务已开始」提示，结果走客服消息（48h/5 条窗口，超窗静默丢弃并记日志）；文本分片 ≤2048B；图文卡片承载文件下载链接（产物上传至服务端临时存储，24h 有效）。
- **FR-IM-13（S）** 测试号模式：个人用户填测试号凭证（本地回调需穿透——产品内明示这是开发用途，附指引）。

### 3.5 横切

- **FR-IM-14（M）** 通道状态进助理模式总控台（模块 03 FR-MC-01 消费）：状态灯/错误原因/快捷设置跳转。
- **FR-IM-15（M）** 安全：白名单外消息一律忽略（可配置回应一句「无权限」）；所有通道消息进助理历史前做来源标注；凭证与回调密钥全量密文存储。
- **FR-IM-16（M）** i18n 8 语言；错误码映射表三通道全覆盖。
- **FR-IM-17（C）** 飞书扫码增强（对标 Workbuddy 的 lark-cli 体验，**v1 不做、显式留口**）：① 扫码授权用户身份（读日历/云文档/邮件等，走官方 lark-cli 设备码流程）；② 扫码新建应用（本机 lark-cli 代建自建应用，app_id 自动回填，App Secret 仍需用户复制一次——lark-cli 的 secret 只进不出，锁在系统钥匙串，读不出真凭证时宁可拒绝导入也不顶掉已存可用凭证）。依赖本机安装 lark-cli（MIT），涉及飞书 OAuth 授权码/设备码能力边界，v1 以「粘贴凭证 + 整页自动识别」覆盖主路径，扫码项待一期后按使用数据决定。

## 4. 非功能需求

| # | 需求 |
|---|---|
| NFR-IM1 | 连接稳定性：WSS 断线自动重连（指数退避 ≤5min）；重连后消息不丢（平台重推 + 去重兜底）；30 天连续在线无内存泄漏（ soak 测试） |
| NFR-IM2 | 时延：消息到达 → AssistantDispatcher 入队 ≤2s（P95）；回推发送 ≤5s（P95，不含模型执行） |
| NFR-IM3 | 限流合规：各平台限速内自我节流（飞书 5 QPS/用户、企微 30 条/分钟/会话），超限排队不报错给用户 |
| NFR-IM4 | 中继可用性：服务端中继无状态化（可横向扩）；bot 绑定关系持久化，客户端离线时消息暂存 ≤24h 重投 |

## 5. 里程碑与验收

| 里程碑 | 内容 | 验收 |
|---|---|---|
| M-IM1 | ChannelAdapter 框架 + 飞书通道 | FR-IM-01~07；真机：手机私聊+群@下任务、文件回传、断网重连 |
| M-IM2 | 企微智能机器人通道 | FR-IM-08~09；流式回复真机验证 |
| M-IM3 | 服务端中继 + 公众号通道 + 收尾 | FR-IM-10~16；组织环境端到端；Gate IM |

**Gate IM（模块出口）**：全部 M 级验收；三通道真机回归（含消息去重/限速/离线暂存重投）；安全自查（凭证存储/白名单/回调验签）通过；与模块 03 联测（助理历史/审批回路跨渠道）通过。

## 6. 名词术语

| 术语 | 定义 |
|---|---|
| ChannelAdapter | 统一通道接口：connect/receive/send/sendFile/status，向模块 03 供给 |
| 长连接模式 | 飞书 WS / 企微智能机器人 WSS——客户端主动外连，免公网 IP |
| 服务端中继 | apps/server 接收公网回调（公众号/企微自建应用）→ WS 下发到绑定桌面的转发层 |
| bot 绑定 | 服务端记录「哪个 bot 凭证 ↔ 哪个客户端连接」的路由关系 |
| 客服消息窗口 | 微信公众号「用户发消息后 48h 内可回 5 条」的限制 |
