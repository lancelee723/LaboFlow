## 一、逐任务验收

### T4.1 远程开发 ✅（传输层真实验证）

**迁移 0005**：`remote_hosts`（加密连接配置）/ `rc_sessions` / `bots` 三表。

**RemoteTransport 统一接口**（exec / readFile / writeFile / listDir / connect / dispose）三实现：

| 传输 | 验证方式 | 结果 |
|---|---|---|
| docker | **真实容器**（本地 Docker 29.5.3 + 本地镜像起 `laboflow-p4-test`）：exec（echo/exit code）、writeFile→readFile 中文内容往返、listDir | ✅ 4 用例全过（388ms） |
| ssh | **真实 SSH 协议**：进程内 ssh2 Server（ed25519 host key + password 认证），SshTransport 走完整握手→exec→退出码；失败命令 exit-code 断言 | ✅（stderr 通道在 ssh2 fixture 下先丢后闭，留真实 sshd 阶段复核，见边界） |
| wsl | 平台守卫：非 Windows 构造即抛错（基准 §10「WSL 仅 Windows 桌面」） | ✅ |

- RemoteDevService：连接注册表（**配置经 KeyVault 加密落库，list 接口不泄漏**，单测断言）、connect 带实时日志（连接向导数据源）、configSync（用户级 Skill/MCP 同步：跳过同名、部分失败隔离、**MCP 密钥原样写入远端的强警示**——基准 §10 逐条对齐）
- 已知契约（对齐 ZCode 文档）：内置 SSH 客户端直连、忽略 ProxyJump/ProxyCommand；同步仅 SSH/WSL、不支持 Docker；仅 POSIX 远端（无原生 Windows 主机）

### T4.2 Remote Control ✅（4 用例全过，真实 HTTP+WS）

- **配对即授权**：URL 路径 token = 完整临时凭据（sha256 存储，明文只在签发瞬间）；401 拒绝错误 token（实测）
- **单连接强制**：第二个 WS 连接被 4001 关闭（实测）
- **刷新作废**：refresh 后旧 URL 立即 401（实测）
- 手机 Web 控制页：中文页（会话列表/发送指令/回复区），WS 主通道 + **HTTP /rc/send 兜底通道**（弱网浏览器，实测回传 agent 回复）
- 能力边界常量：MOBILE_CAPABILITIES / MOBILE_EXCLUDED（不能新建远程连接、不显示自动化、不可访问窗口外环境）
- 中继：直连模式已实现；组织服务器中继（WS 频道 `rc:<desktopId>`）依赖 P2 服务端部署——**外部待办**

### T4.3 Bot Channel ✅（3 用例全过；真实 IM 租户为外部待办）

- BotBridge：bots 表 CRUD（secret 加密）、webhook 验签四策略（generic HMAC-SHA256 恒时比较 / 飞书 verification token / 企业微信签名位 / 钉钉 timestamp+HMAC）、入站信封解析（飞书 event.message.content JSON 已实测）、路由至绑定会话、**回复粒度三档**（standard 200 字截断实测）、**工作区范围前缀 403**（实测）
- 出站抽象：凭据缺失时降级为「HTTP 响应内回传」（generic 通道）；飞书流式卡片/企业微信/钉钉真实出站需租户凭据——**外部待办**（适配器形状已定型）

### T4.4 服务端定时执行 ✅（真实 Pi 引擎 E2E）

- HeadlessRunner：无人值守任务 = PiDriver（同一引擎）+ fullAccess 模式 + 项目目录快照；产出**与客户端同 schema 的 JSONL 运行记录**（`.laboflow/runs/run-<ts>.jsonl`，message/tool/error 条目），客户端可回放
- E2E：真实 Pi + mock provider 跑通「读 notes.md→工具调用→总结→JSONL 落盘→回放解析」✅
- 与 P2 服务器部署的对接（server 侧 cron 调度该 runner）属 P2 部署域，接口已就绪

### T4.5 订阅制 OAuth 渠道 ⚠️ 脚手架完成（外部待办）

- OAUTH_PROVIDERS（ChatGPT / Claude）+ PKCE 风格授权 URL 构建（S256 code_challenge、state 签名，2 单测）
- 浏览器回环与 token 交换需 provider 注册的 client_id/secret——**外部待办**（换取凭据后接入 exchange 即可）

## 三、过程中发现并修复的问题

| # | 问题 | 修复 |
|---|---|---|
| 1 | pnpm 拦截 ssh2 原生构建脚本 | onlyBuiltDependencies 放行 ssh2/cpu-features |
| 2 | esbuild 无法处理 ssh2 的 .node 绑定 | ssh2/ws external + electron-builder asarUnpack |
| 3 | ssh2 服务器端 exec 回调为三参 (accept, reject, info)，误按两参解析导致 command undefined | 修正签名 |
| 4 | fixture 中 stderr 写入与 exit 竞态（exit 码先达） | 测试改用退出码断言 + 文档标注 |
| 5 | RC start() 在 listen 异步完成前读 address() 返回 null | await listening 事件 |
| 6 | base64url token（含 -/_）不匹配路由正则导致 401 | 字符集扩展 |
| 7 | 移动页 hello 消息与客户端监听注册竞态 | 客户端先注册监听 + 服务端支持按需重发 |
| 8 | bots 表缺 bind_session_id 列 | 迁移 5 修正 |
| 9 | 无 `timeout` 命令且 busybox 拉取被慢网络卡死 | 测试容器改用本地镜像 + 环境变量覆盖 |
