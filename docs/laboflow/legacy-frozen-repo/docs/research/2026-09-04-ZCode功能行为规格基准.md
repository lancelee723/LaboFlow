# ZCode 功能行为规格基准（LaboFlow 对标用）

- 基准来源：ZCode 官方文档 https://zcode.z.ai/cn/docs/（v3.10.2，2026-09-04 抓取全部 22 页）
- 用途：LaboFlow 功能对标的行为级验收基准。**只对标行为与格式，不接触其代码与内部实现**（合法边界：公开文档 + 行为观察）
- 结构：18 项核心功能 + 3 项补充（安全确认/快捷键/ADE）；每项给出 LaboFlow 需要对齐的关键语义

---

## 1. ZCode Agent（会话核心）

对齐要点：
- **输入框内联符号**：`@` 引用文件/文件夹、`/` 命令面板（命令+技能两分组）、`$` 调用 Skill（标签形式入输入框）、`#` 引用历史会话为上下文；`+` 按钮统一入口（附件/@/#//）。
- **模型/执行模式/推理强度任务中途可切**；推理强度三档（低/高/最高，默认最高）。
- **免项目聊天**：「不在项目中工作」模式；创建的文件留磁盘需手动清理；首条消息后模式固定；无 Git 分支选择器。
- **长文本粘贴自动转附件**（输入框只显附件条目，完整内容仍发给模型）。
- **划选追问**：选中回复/思考/代码/工具输出片段 → 浮动工具栏 → 「添加到当前任务」（引用旁挂）或「在辅助对话中提问」；流式中划选会冻结文本；仅支持单行内选择；引用有长度/条数/总大小上限，超限显式提示不静默截断。
- **辅助对话（/side、/btw 等价，不作为消息发送）**：携带主会话历史作为上下文但 UI 从空白开始；具备完整能力（工具/编辑/权限确认）；不继承 goal/发送队列/后台任务；每主任务单窗口限一个；主任务运行/待确认时「+」入口可用而浮动工具栏不可用；关闭不可恢复。
- **会话分叉**：悬停**稳定完成**的 assistant 消息 → 分叉；继承分叉点前历史+当时模型/推理强度/goal 进度；不回滚磁盘文件；队列/后台任务不复制；压缩中禁止分叉；新任务标题 "Fork of <原标题>"。
- **AGENTS.md 注入**：用户全局（`~/.zcode/AGENTS.md`）在前 + 工作区 `AGENTS.md` 在后拼接；不读 CLAUDE.md（一次性迁移引导）。
- 快捷键：模型菜单 Ctrl/⌃+M、思考强度 Ctrl/⌃+T、模式循环 **Shift+Tab**（输入框聚焦时）。

## 2. 目标模式（Goal Mode）

- `/goal` 查看 | `/goal <描述>` 设定（覆盖） | `/goal replace <目标>` | `/goal pause` | `/goal resume` | `/goal clear`。每会话同时仅一个 goal。
- **逐轮自动校验**：每轮结束跑独立 verification pass；未达成 → 给出下一步动作自动开下一轮；达成 → 收尾总结。**证据导向**：计划/todo/长耗时/「像结论的回复」均不算，只认可验证产物（文件/命令输出/测试结果）；有未完成 todo 时不得判完成。
- Checklist 条目固定挂首次出现的轮次。右侧 goal card（目标+已用时长）+ 按迭代分组 checklist。
- 中途干预自然语言即可（换向/暂停/放弃 → replace/pause/clear）；按停止自动 pause；goal 状态随会话持久化，重开恢复。
- 终止三条件：校验达成 / 用户暂停清除 / usage limit 触顶。
- 计划模式与运行中不可设 goal（UI 显因）。

## 3. 浏览器自动化

- 官方插件提供、默认启用；**内嵌浏览器**独立登录态（不共享日常 Chrome）；开关仅对新会话生效。
- **标签认领制**：Agent 默认只操作自己打开的标签；用户手动开的标签需显式认领才接管；标签跨对话留存。
- **Chrome 数据快照导入**：一次性导入最近 Chrome Profile 的 Cookie+LocalStorage（不同步、不改动 Chrome、不读密码；Windows 暂缺、macOS 需钥匙串权限）。
- 视口切换（如 375×812，面板自由尺寸模式）；**网页文字不作为指令**（防 prompt injection）；暂不支持上传文件。
- 数据清理两级：「清除缓存」（HTTP/Cache Storage/SW，保留登录态）与「清除全部」（含 Cookie 站点数据，二次确认不可撤销）。
- 自己浏览：地址栏/导航/DevTools；file 协议；文件树 HTML 右键「用内置浏览器打开」；**元素点选按钮**把元素（标题/URL/文本/选择器/位置/安全 HTML 摘要）选为聊天上下文。

## 4. 任务与文件管理

- 任务视图三模式：**分组**（自定义、7 色）/ **工作区** / **时间线**；排序按创建/更新时间；搜索（命令/会话/文件）；归档列表。
- **自动归档四条件**（同时满足）：已完成 + 无未读 + 未置顶 + 超保留期（3/7/14/30 天可配）；归档项可恢复/永久删除。
- 文件树：文件名/路径实时过滤；「仅显示变更文件」；Git 状态标识（新增/修改/删除/重命名 + 目录聚合点）；单击预览、双击编辑器、**拖拽到对话自动插引用**；右键（打开/打开方式/添加到聊天/复制路径/资源管理器中显示）。
- **Git 图谱**：只读 commit graph（分支并排、merge 可见、分页加载、commit 详情悬停）；不能切分支/看变更；分支切换在 dropdown 上半部（未提交变更时提示或「提交并切换」）。
- **命令中心** Ctrl/⌘+K：命令/对话/文件三类搜索 + 快捷操作。

## 5. Wiki（仓库 Wiki）

- 入口：文件树顶部仓库名旁图标；全屏打开；远程断连/只读时隐藏。
- 生成选项四项：语言（中/英，默认随界面）、模型（默认随聊天模型可临时换）、生成图表（默认开）、重试次数（默认 0）。
- 过程：分析代码库 → 生成目录 → 生成页面 → 保存；**生成中即可读已完成页**；停止保留已完成页。
- 阅读器：两栏（项目/TOC + 正文），可拖分隔、可折叠、窄屏堆叠；元数据（分支/语言/更新时间/commit ID/页数）；**每条结论带 文件路径+行号 可点击跳转**；Mermaid 主题适配/缩放。
- 内容优先级：项目定位/主执行链/核心模块/跨平台边界/数据与状态流/配置边界/扩展点/风险点；排除安装部署/CI 等通用章节。
- **自动刷新**：每轮对话结束时检查代码实际变更，变更才刷新。
- **隐私过滤**：不进模型上下文——.git、依赖、构建产物、缓存、.gitignore 命中、敏感词文件名（token/secret/credential/password）的可疑文件、symlink 目标；逐层按需读取不给预构建清单。
- 限制：每仓库同时仅一个生成任务；仅一种语言版本（换语言覆盖）；无单页重生成/历史版本；单请求 3 分钟超时；**工具式 TOC/页生成当前仅支持 OpenAI Chat Completions 协议**。
- 存储：`~/.zcode/v2/repo-wiki/<工作区哈希>/wiki.json`（全部页面 Markdown+源码引用的纯 JSON，不写入仓库）。

## 6. Memory（项目记忆）

- 开关：设置→常规，**默认关闭**；仅对新会话/重启恢复的会话生效；作用域=项目；仅主对话读写，subagent 不读不写。
- **提取**：每轮成功结束后后台回顾，值得保留才写；内容四类——用户（偏好）/反馈（对 Agent 的纠正）/项目（约束进展）/参考（外部资源）；**刻意不记**：代码结构、Git 历史、AGENTS.md 已有内容、临时信息。
- **召回**：新会话自动加载索引；索引超限截断（条目保持精短）。
- 自然语言管理：「记住，…」立即存；「忘掉…」删除；可问「你记住了哪些」。
- 存储（本地 Markdown 可手编）：`~/.zcode/cli/memories/projects/<project>/memory/MEMORY.md`（索引）+ `*.md`（每事实一文件）。
- ZCode 缺应用内管理页（LaboFlow 计划补齐：管理页可查看/编辑/删除记忆条目）。
- 额外 Token 消耗需在用量统计可见。

## 7. 自动化（定时任务）

- 入口：左侧「自动化」页（非 Settings）；三创建方式：表单 / 会话内创建（绑 session，之后每次结果进同一 session）/ 4 模板（工作日晨会动态、每日风险扫描、周五发布简报、周三文档同步检查——只读分析导向）。
- **频率为结构化选择器（无 cron 表达式 UI）**：单位（时/天/周/月/年）× 间隔（每 N）× 点位（周几/几号/几点几分）；每月支持「按日期」或「按第几个星期几」；折叠为短摘要可再编辑。
- 结束条件：默认无限；可设结束日期（到期→已完成）。**无最多运行 N 次 UI**。
- 时区=本机本地。
- **错过不补跑**：休眠/未运行记「跳过」（成功/失败/跳过三态）。
- **立即运行**：不扰动计划与计数；上一条运行中不排队（单任务单并发）。
- **全局上限：所有项目合计 20 个任务**（暂停/完成/失败均占额，删除才释放）。
- 状态：运行中/已暂停/已完成/失败；详情页「设置/历史」两 tab；暂停保留任务置灰可恢复。
- 「保持唤醒」全局开关（与闲时任务共享）。仅本地项目（remote 不可新建）。

## 8. 闲时任务

- ZCode 语义：无时间表、一次性、全局 FIFO 队列、**服务端算力富余时段执行且自动轮免费**（订阅制经济学）；长任务分段续跑回原 session；Esc 中断即终态接管计费；后台 subagent 不支持；每日创建上限。
- **LaboFlow 适配（语义差异需在 PRD 明示）**：LaboFlow 为 BYOM/私有网关，无「服务端免费算力」概念 → 闲时任务 = **本机闲时队列**：一次性任务排队，满足闲时条件（无活跃会话 + 可选系统空闲 N 分钟）自动执行，消耗计入用户渠道/组织配额。其余对齐：FIFO、可见排队位次、暂停/继续/取消、执行中可插话（排队至当前轮结束）、失败不自动重试、每日创建上限。

## 9. 编辑历史对话

- **仅最新一轮 user message 可编辑**（绝不改 Agent 回复）；运行中/排队中不可编辑；编辑时可继续用 @ / /。
- 提交=按更新消息重发（保留模型/工作区/分支/上下文）。
- **「对话+文件重置」**：恢复本轮更改文件至改前状态 + 重发修正消息；任一文件无法安全恢复（用户手改过等）→ 提示可选「仅重置对话并发送」；运行中/压缩中/无可恢复更改时不可用。
- **Undo/Reapply（全有或全无）**：确认窗列出可撤销/不可撤销/忽略清单；不可撤销=未保存改前内容的文件、用户手改过的文件、终端命令引起的变更（走 Git）；撤销后可 Reapply。
- 排队消息编辑=撤回输入框重发（非原地）；队列压缩命令无编辑入口。

## 10. 远程开发

- 三通路：**SSH**（内置客户端直连、默认 22、支持 ~/.ssh/config 别名、**忽略 ProxyJump/ProxyCommand**、凭证加密存本地）、**WSL**（仅 Windows 桌面；慎用 root）、**Docker**（docker exec/cp，容器名或 ID）。**不支持原生 Windows 远程主机**（需 POSIX shell）。
- 远端装 `~/.zcode/server` 组件；资源两种下发：本地下 SFTP 上传（远端可离线）或远端直连 CDN。
- 桌面端只留：账号、模型配置、任务入口、UI；文件/命令/Git/Agent runtime 在远端。
- **配置同步**：Skill/MCP/Plugin 三项、仅用户级（项目级技能/工作区 MCP/插件捆绑 MCP 除外）、手动触发、跳过远端同名、部分失败不影响成功项；**MCP 密钥原样写入远端——仅同步到受信任主机**；同步不支持 Docker。
- 移动端仅可触发重连。

## 11. Remote Control

- 桌面左下手机图标 → 弹窗：左 QR+URL、右 Bot Channel 入口。
- 控制端=**手机浏览器 Web 页**（无独立 App）；连接挂载到**整个桌面窗口**（非单个工作区）；**同时仅一个手机连接**。
- **URL 即完整授权**（临时密钥）；关闭弹窗不断连，必须点「停止」；怀疑泄露→**刷新 QR 作废旧地址**强制重扫。
- 手机可：按工作区/时间线看任务、排序、刷新、已有工作区内新建任务、触发远程工作区重连、session 页发指令、复制/点赞/点踩、条件性 fork。不能新建远程连接、不能看窗口外环境。
- 桌面必须在线；指令实际执行位置由工作区类型决定（local/SSH/WSL/Docker）。

## 12. Bot Channel

- 已支持：微信（扫码绑定）、飞书/Lark（扫码建应用 + 限时绑定命令 `/bind C67356`）；规划：钉钉、Discord、企业微信。
- 流向：IM 消息 → Agent；进度/结果 → IM。**飞书流式卡片**：单卡原地更新、工具段折叠、需决策时旧卡冻结+新卡提问。
- Bot 管理：链接/解绑、**回复粒度**（标准/完整/摘要；飞书除外）、**工作区访问范围**限制、启停、连通状态、删除。
- LaboFlow 取舍：面向咨询团队优先 **飞书/企业微信/钉钉**（微信个人号合规风险高，可选）。

## 13. 子智能体（Subagents）

- 内置 `general-purpose`（全工具）与 `Explore`（只读调研：Read/Grep/Glob/WebFetch/WebSearch）；后台 Explore 仅只读工具。
- 前台并行（主任务等待全部完成）/后台（完成自动回主对话）；**子智能体内不能再派子智能体**；仅见启动时已连接 MCP；定义修改需新建会话生效（未指定 model 的跟随主会话切换）。
- 定义文件：`~/.zcode/agents/<name>.md`，frontmatter（camelCase）：`name`/`description`（必填）、`model`（`inherit`=跟随）、`thoughtLevel`（需同时配 model）、`color`、`tools`/`disallowedTools`（空或 `*`=继承全部含 MCP；MCP 工具须写全名 `mcp__<服务>__<工具>`，通配无效）、`maxTurns`、`injectAgentsMd`（默认 true）、`mcpServers`（未连接即调用失败）。**正文=system prompt**。未知字段静默忽略。
- LaboFlow 对齐：专家（Agent.md+Soul.md）磁盘格式与该格式兼容（Soul 内容并入正文或扩展字段），同时支持插件 `agents/*.md` 注册。

## 14. Plugin

- 目录：`.zcode-plugin/plugin.json`（**优先**）或 `.claude-plugin/plugin.json`（兼容）；组件目录 `commands/` `skills/`（单层）`agents/` `hooks/hooks.json` `.mcp.json`。
- `plugin.json`：`name`（正则 `^[a-z0-9][a-z0-9._-]{0,127}$`）、`version`（缺省 0.0.0）、`description`、`author`、`homepage`/`repository`、`license`、`keywords`、五类组件键（目录字符串/路径数组/内联对象）、`dependencies`（`name@market` 或同市场裸名）、`userConfig`（type=string/number/boolean/directory/file；title/description/default/required/sensitive；敏感值经 `${user_config.键}` 注入 MCP 声明）。
- `marketplace.json`：顶层 `name`（必填）、`description`、`plugins[]`（必填：name/source/description/version/category/tags/dependencies/strict）、`pluginRoot`、`allowCrossMarketplaceDependenciesOn`。**source 七种**：相对路径 | `{"source":"directory"}` | `github`（repo/path/ref）| `git`（url）| `file` | `url`（指向 marketplace.json，可带 headers）| `npm`。
- `.mcp.json`：`mcpServers` 每项 stdio `{type,command,args,cwd,env,enabled,timeoutMs}` 或 `{type:"http"|"sse",url,headers}`；type 可省略（有 command=stdio，有 url=http）；变量 `${CLAUDE_PLUGIN_ROOT}`（兼容 `${ZCODE_PLUGIN_ROOT}`）/`${CLAUDE_PLUGIN_DATA}`/`${CLAUDE_PROJECT_DIR}`/`${user_config.*}`；键名命名空间 `plugin:<插件>:<服务>`。
- 市场：公开目录（GitHub 收录）+ 个人自建（GitHub 仓库/Git URL/本地清单或目录拖拽）；预置 Claude Code 插件市场。
- 行为：新装默认启用；停用=全部组件立即移除（再启用恢复）；卸载内置插件记屏蔽标记（升级不装回）；版本对比=市场 `marketplace.json` version vs 插件 `plugin.json` version；本地缓存清单需手动刷新。
- 安全：启用=授予代码执行信任；审查 hooks/hooks.json 与来源。

## 15. Skill

- 位置：`~/.zcode/skills/<name>/SKILL.md`（用户级）；插件内 `skills/<name>/`（**单层**，嵌套不识别）。
- frontmatter：`name`（必填/缺省取目录名）、`description`（必填 ≤1024 字符，超限整技能丢弃）、`when_to_use`、`license`、`metadata`；非白名单字段忽略。
- 正文 >100KB 截断加载。**元数据预算**：每轮注入所有已启用技能的 名称+描述摘要（单条 ≤250 字符），共享固定 token 预算，超预算降级为仅名称（自动触发率骤降）→ 提示只启用常用技能。
- 使用：`$技能名`（标签入输入框）或 Agent 自动触发；`/` 面板技能分组。
- **外部导入**：扫描 Claude Code/Codex CLI/OpenClaw/Augment/Windsurf 技能目录 → 软链（跟随来源）或复制（独立副本）→ 目标全局或当前项目。

## 16. MCP

- 作用域与路径：用户级 `~/.zcode/cli/config.json`（键 `mcp.servers`）/ 工作区级 `<项目根>/.zcode/config.json`；兼容兜底 `~/.agents/mcp.json` 与 `<项目根>/.agents/mcp.json`（键 `mcpServers`）；**同作用域内 `.zcode` 有任何服务则 `.agents` 整体跳过（不合并）**；设置页写入永远落 `.zcode`。
- 停用=配置内 `"enable": false`（无字段即启用）。工作区 MCP 会话启动自动连接（**同名以用户配置为准**）；打开陌生仓库先查 `.zcode/config.json`（安全提示）。
- 类型：stdio（本地命令）/ SSE / HTTP。**OAuth 仅 HTTP/SSE**：行内「打开授权」→ 系统浏览器 → 自动重连；未完成标记失败不阻塞会话。
- 新建：表单或粘贴 JSON（兼容 `{"server":{...}}` 与 `{"mcpServers":{...}}`）。导入：Claude Code `~/.claude/settings.json`、Codex `~/.codex/config.toml`、OpenCode、`~/.agents/mcp.json`；可全选、默认启用、不动原文件。
- 子智能体引用：`mcp__<服务>__<工具>` 全名 + frontmatter `mcpServers` 字段。

## 17. Command

- `/` 面板 = 「命令」+「技能」两分组；命令可带参数提示。
- **内置仅 `/goal` 与 `/compact`**。
- 自定义：设置表单（作用域 用户/工作区、名称、描述、参数提示、提示词）或 `.md` 文件：用户级 `~/.zcode/commands/*.md`、工作区级 `<项目根>/.zcode/commands/`。
- frontmatter：`description`（必填或正文非空）、`argument-hint`（如 `"[topic]"`）、`allowed-tools`（逗号分隔）、`model`、`skills`（自动挂载技能）、`disable-noninteractive`。正文变量 `$ARGUMENTS`/`$1`/`$2`。文件名=命令名，正则 `^[a-z0-9][a-z0-9_:-]{0,63}$`。
- 外部 Agent 命令导入。分发：插件 `commands/*.md`。
- 与 Skill 分工：简单提示词=Command；脚本/模板/完整方法=Skill。

## 18. Hooks（完整子进程协议）

- 事件与顺序：`SessionStart` → `UserPromptSubmit` → 主模型 → `PreToolUse` →（需确认时 `PermissionRequest`）→ 执行工具 → `PostToolUse` / `PostToolUseFailure` → `Stop`（block 可续跑，**最多连续 3 次**）。
- matcher：空/`*`=全部；纯 `[A-Za-z0-9_|]`=精确名列表；含其他字符=JavaScript 正则（非法不执行出诊断）；SessionStart 匹配 source（startup/clear/compact）；UserPromptSubmit 与 Stop 不过滤。
- 执行器：`process`（command+args[] argv 直执、同步、推荐）与 `command`（shell 字符串、可 async/timeout，兼容 Claude 插件）。默认超时 60000ms、stdout 上限 32768 bytes；`timeoutMs` 优先于 `timeout`（秒）。
- stdin：一行 JSON（camelCase 与 snake_case 别名并存）：`session_id`/`transcript_path`（临时 JSONL）/`cwd`/`permission_mode`/`hook_event_name`/`tool_name`/`tool_input`/`tool_use_id` + 各事件专有字段（SessionStart.source、UserPromptSubmit.prompt、PermissionRequest.permission_suggestions、PostToolUse.tool_response、PostToolUseFailure.error/is_interrupt、Stop.stop_hook_active/last_assistant_message）。
- stdout 决策（去前导空白后以 `{` 开头才解析）：`additionalContext` 注入；PreToolUse `permissionDecision: allow|deny` + reason + `updatedInput`（完整替换、重校验 schema；聚合 **deny > ask > allow**）；PermissionRequest `decision.behavior` + `updatedInput`/`updatedPermissions`（**显式 deny、Plan 写入禁令、工具硬限制不可被 allow 绕过**）；UserPromptSubmit `{"continue":false,"reason"}` 阻断；Stop `{"decision":"block","reason"}` 续跑。退出码 0=成功、2=阻断快捷方式、其他=可恢复失败。
- 来源：用户级 `~/.zcode/cli/config.json`（须 `hooks.enabled:true`）+ 插件 `hooks/hooks.json`；**项目级 hooks 当前整体忽略**；user 先于插件、同源按数组序；**会话快照**（改配置需新会话验证）。
- 环境变量：`ZCODE_PLUGIN_ROOT`/`ZCODE_PLUGIN_DATA`/`ZCODE_PLUGIN_ID`/`ZCODE_PLUGIN_NAME` + Claude 兼容名；持久数据写 PLUGIN_DATA。

## 19. 使用统计

- 应用用量（本地本机）：Token、会话数、消息数、活跃天数、**当前连续天数/最长连续天数**、**高峰时段**；四图：按天 Token 趋势（悬停按模型明细）、**活跃热力图**、模型用量排行、模型用量环图；时间筛选 全部/30 天/7 天。
- 编程套餐（远端）：5 小时池/每周额度/MCP 月额度、模型消耗、工具调用次数、上下文构成 + 额度重置卡体系（闲时自动下发三条件）。
- LaboFlow 映射：应用用量对齐本地统计（含热力图/连续天数）；「编程套餐」面板 → **组织网关配额面板**（余量/重置周期/触顶告警；重置卡体系不适用——配额按周期自然重置）。

## 20. 安全操作确认（补充）

- 四档执行模式（默认**变更前确认**）；Shift+Tab 循环切换。
- 决策按钮：**允许 / 始终允许 / 拒绝 / 始终拒绝**，部分场景细粒度 **允许本会话 / 始终允许本项目**。
- 确认流程：触发（任务暂停输入阻塞）→ 展示精确命令/变更/调用 → 决策 → 归属当前任务（切换任务回来状态保留）。
- **提问 5 分钟倒计时自动继续**（仅普通问题；权限请求与计划审批无限等待）；任何交互（悬停/开始选择/点秒数/停止计时）**永久停止**该倒计时；开关在设置（默认开、关闭不追溯）。
- 触发场景：第三方脚本、网络请求、文件变更（含撤销入口）、系统级命令；高权限/全自动模式工具栏持续风险警告。
