## 一、产品定位

本地优先的 macOS 个人 AI 工作站（"会听、会说、会动手"）：语音交互、并行子代理、产物交付（PPT/研究报告/文档/设计稿）、Loop 自动化、IM 推送。个人独立开发者（@daveylan2），装机约 3,000。1.0.1 起增加团队工作区/服务器工作区（绑定作者私有云），1.0.2 增加 IM 渠道——正向轻 2B 演进，但**闭源 + 私有云 + macOS 单平台**，与 LaboFlow 的目标市场（咨询团队、私有化、三平台）不构成正面竞争，反而验证了「Agent 工作台团队化」的需求真实性。

## 二、技术栈全景（逆向确认）

| 层 | Cortex 的选择 | 与 LaboFlow（SPEC v1.1）对照 |

| 浏览器 | agent-browser 0.31.1（Apache-2.0 独立二进制） | LaboFlow 自研 CDP → **v1.2 改为 agent-browser 优先** |

### 3.3 度量与组件

- 圆角：4 / 6 / 8 / 12 / 16 px（sm/md/lg/xl/2xl）；间距基数 4px；过渡 150ms `cubic-bezier(.4,0,.2,1)`
- 字体：`ui-sans-serif / system-ui` 系统栈（未引入自定义字体）；等宽 `ui-monospace/SFMono`；正文 14px（text-sm）、辅助 12px（text-xs）
- 图标：**自绘线性描边体系，89 个**（Icon 组件内联 SVG path；默认 16px、stroke-width 2，个别 2.4；12px 用于时间线小图标）
- 侧栏宽度 256px（w-64），展开态 288px（w-72）；玻璃侧栏 `color-mix(srgb, bg-sidebar 52%, transparent)` + backdrop-blur
- 消息流为「过程时间线」形态：思考节点（Lightbulb 12px）、工具节点、子代理派发节点卡片化；产物（artifact）卡片化渲染 + 版本 + 分屏对比

> LaboFlow 现状（packages/ui）：蓝灰冷调（bg `#F8FAFC`、accent teal `#0E7490`、border 半透明蓝灰）+ emoji 占位图标——与 Cortex 暖灰黑白体系是两种语言，此即「不够高级」的主因。v1.2 附录 D 给出融合裁决。

## 四、许可证边界（合规红线）

| 资产 | 许可 | 能否用于 LaboFlow |
|---|---|---|
| Cortex 应用全部代码（@cortex-work/*、out/*、二进制 sidecar） | **无 LICENSE（保留所有权利）** | ❌ 禁止拷贝/修改再分发；可阅读学习（本机） |
| @earendil-works/pi-* | MIT | ✅（LaboFlow 已在用） |
| compound-engineering skills（ce-*，6 个） | MIT | ✅ 可内置（保留版权声明） |
| agent-browser 0.31.1 | Apache-2.0 | ✅ 可依赖其二进制/包 |
| @firecrawl/anydoc | 开源（以仓库声明为准，接入时复核） | ✅ 预期可用 |
| croner / nodemailer / html-to-docx / jszip / sherpa-onnx(Apache-2.0) / onnxruntime(MIT) / lucide-react(MIT) | 宽松 | ✅ |
| Cortex 的 UI 视觉规格（布局/色值/度量） | 思想/功能层面不受版权保护 | ✅ 作为基准自实现；**图标/logo 等美术资产不得拷贝，用 lucide-react 或自绘同形替代** |

结论：**不 fork、不搬码**；Cortex 的价值 = 架构参考（worker 进程模型、产物工作台、双链 skill 机制）+ 设计 token 基准 + 开源组件清单 + 竞品验证。

## 五、对 LaboFlow 的行动映射（→ v1.2 文档）

1. **ADR-13 引擎 worker 进程化**：EngineHost utility process + stdio JSON RPC（方法集对齐 pi-host），崩溃隔离 + 权限边界清晰；现有 PiDriver 重构为 EngineHostClient（SPEC §4.2）。
2. **组件替换**：anydoc（附件解析 23 格式）、croner（调度）、agent-browser（Browser Use 执行器，自研 CDP 回退）、lucide-react（图标）、html-to-docx（Word 交付物）。
3. **新增产品能力**（PRD v1.2 新 FR）：会话产物工作台、Slide 引擎、深度研究、全局捕获三件套、本地语音、Loop 工作流、消息中心、写作模式、媒体生成。
4. **UI 像素级对齐**（附录 D）：结构/交互以 ZCode 为基准，视觉 token 取 Cortex 实测值，图标换 lucide 自有化。
