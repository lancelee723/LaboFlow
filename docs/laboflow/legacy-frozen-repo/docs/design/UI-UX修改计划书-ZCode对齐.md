## 一、ZCode 设计语言提取（从截图实测）

### 1.1 版式骨架（用户点名的核心：「三区圆角方框」）

- **窗口底色与内容分层**：整窗浅暖白底；**左栏与右侧内容区是两块分离的「圆角方框」**，中间留出约 8–12px 的底色缝隙——不是传统的 1px 边框分栏。右内容区自身是一个大圆角（≈16px）卡片浮在底色上。
- 推广到多面板：凡并排区域（列表/详情、导航/内容）一律「各自圆角卡片 + 底色缝隙」表达分区，**废除全部竖直 1px 分隔边框**。
- 设置/管理类页面是「全屏页」而非对话框：左导航栏 + 右内容区，同样两块圆角方框；顶部「← 返回工作区」。
- 窗口红绿灯融入左栏顶部（无独立标题栏背景）。

### 1.2 配色（实测值）

| 用途 | 值 |
|---|---|
| 窗口/左栏底 | `#F7F7F5` 级暖白（左栏带极淡对角渐变） |
| 内容卡片 | `#FFFFFF` |
| 卡内嵌套卡/输入 | `#F4F4F2` |
| hover / 选中 | `#EFEFED` / `#EBEBE9` |
| 边框（仅虚线空态与次按钮描边） | `#E4E4E2` |
| 文字主/次/辅/占位 | `#1A1A1A` / `#6B6B68` / `#9C9C98` / `#B8B8B4` |
| **主操作色** | **纯黑 `#1A1A1A` 底白字**（+新建 / 升级 / 新建技能），次操作白底灰描边 |
| 权限模式语义 | **单一橙色** `#E8842C`（图标+文字），选中项浅橙底胶囊；无四色体系 |
| 状态点 | 绿=已连接/正常、红=错误、灰=宿主管理/停用（图标右下角 6px 圆点） |
| 进度条 | 绿 `#2E9E44`（额度余量） |
| 图表 | 按模型分色的蓝/绿平滑曲线，图例点+模型名 |

结论：LaboFlow v1.2 附录 D 采用的「黑白无彩强调 + 暖灰」方向与 ZCode 同族，但**当前实现是冷灰+teal 残留**（`--lf-accent: #0e7490` 等），且模式四色/彩色按钮过多。本计划全面切换到上表实测值，**废除 teal 与权限四色**。

### 1.3 组件形制

- **按钮三级**：主=黑底白字胶囊（`radius 8px`）；次=白底 1px 描边；幽灵=纯文字。无彩色按钮。
- **图标**：全线细线性（≈1.5–2 stroke、20px 导航/16px 行内），单色灰黑；**无 emoji、无彩色图标**——唯一例外是技能/MCP 列表的「类型化方形图标」（文档=黄、浏览器=光标、机器人=机器人脸，带右下角状态点）。
- **列表卡片行**（技能/MCP/子智能体/插件通用）：浅灰底圆角行（选中/hover 更深），左侧类型化方形图标（40px 圆角方块），中间名称粗体+单行截断灰描述（可带标签胶囊如「全部工具」「7 个工具」「默认」「User 默认」），右侧操作（开关/下拉/按钮）。
- **菜单/下拉**：白底 12px 圆角浮层，条目=图标+粗标题+灰色说明（双行），选中浅灰底+右侧 ✓。
- **开关**：iOS 式黑色（on）/灰（off）。
- **空态**：虚线描边大圆角卡片，居中=粗标题+灰说明+黑主按钮+白次按钮（如「+ 新建技能」「导入」）。
- **输入区**（主界面）：浮起白卡（16px 圆角+淡阴影），内部三行——项目选择行（📁 名称 ▾ 胶囊）、多行输入（占位文案含 @ / 使用提示）、底行（+ | 权限模式钮 | 右侧：模型点+模型名▾+思考▾+↑发送圆钮）。
- **Tab/分段**：胶囊分段（选中白底浮起），如侧栏「# 分组 / 📁 项目」、统计页「每日/每周/累计」「近7日/近30日」。
- **徽章**：绿色「已启用」实心、灰「默认」「Lite」、黑「升级 150% 配额」胶囊。
- **字体**：系统栈；标题 600–700；供应商/模型名用等宽字体（模型列表行）。

### 1.4 交互细节

- 侧栏任务行右对齐灰色相对时间（50分/1天/2天）。
- 每个管理页固定三件套：作用域下拉（🖥 用户/项目）+ 计数 + 右侧大圆角搜索框；「已安装 N」行 + ···/刷新/+新建。
- 主界面欢迎页：居中 Logo 线稿 + **时间感知问候语** + 额度信息条（info+文字+升级胶囊+×）+ 输入卡 + 四个快捷 chips（图标+文字：周报总结/报错修复/PPT 制作/闲时任务）。
- 右上角常驻：? 帮助、面板折叠图标。

## 三、目标设计规范（LaboFlow Design Token v3，直接可实施）

### 3.1 Token 表（packages/ui 重写，暗色为推导值）

```
--bg-window: #F7F7F5        / dark #1B1B1B
--bg-panel:  #FBFBFA        / dark #1F1F1F      （左栏/导航，微渐变）
--bg-card:   #FFFFFF        / dark #242424      （内容圆角方框）
--bg-inset:  #F4F4F2        / dark #2A2A2A      （嵌套卡/输入底）
--bg-hover:  #F0F0EE        / dark #2E2E2E
--bg-active: #EAEAE8        / dark #343434
--border:    #E7E7E4        / dark #3A3A3A      （仅虚线空态/次按钮用）
--text-1:    #1A1A1A        / dark #ECECEC
--text-2:    #6B6B68        / dark #B0B0AD
--text-3:    #9C9C98        / dark #7A7A76
--text-4:    #B8B8B4        / dark #5A5A56
--accent:    #1A1A1A        / dark #ECECEC      （主按钮=黑/白反转）
--perm-color:#E8842C         / dark #F09A4A     （权限模式唯一语义色）
--status-ok: #2E9E44; --status-err: #D6453D; --status-idle: #9C9C98
--chart-1:   #3B82F6; --chart-2: #2E9E44 （趋势图模型色）
radius: 卡片 16 / 浮层菜单 12 / 按钮·输入 8 / 胶囊 999
gap: 区域间 10px（底色缝隙）；页边 16px；行高：导航行 36px、列表行 64px
shadow: 仅浮层（0 8px 24px rgba(0,0,0,.06)）；卡片无投影靠底色分层
motion: 120–160ms ease-out；无弹跳
字体: system-ui；标题 600/700；模型名/命令用 ui-monospace
```

### 3.2 图标规范

- 基础集继续 lucide，**全部单色**，导航 20px/行内 16px/状态点 6px；stroke 1.75。
- 新增「类型化方形图标」组件 `<TypeIcon kind>`：40px 圆角方块（底色 #F4F4F2），内部按类别渲染彩色小图（文档=黄 doc、浏览器=光标、机器人、插件拼图…）+ 右下角 6px 状态点（绿/红/灰）——用于技能/MCP/子智能体/插件列表。

## 四、页面级改造方案（逐页详述）

### 4.1 应用骨架（App.tsx 重构）🔴

- 全局 `AppShell`：`window(bg-panel 渐变) > [Sidebar 卡] + gap(10px) + [Main 卡（radius 16, bg-card）]`；Terminal/右面板作为 Main 卡内部可折叠区，不再是独立边框栏。
- **视图路由**（纯 state，无路由库）：`workspace`（主界面）/ `settings`（全屏设置，含 14 子页）/ `usage`（全屏统计）。设置与统计从「对话框」改为**全屏视图**（ZCode 形制），左上「← 返回工作区」。
- 右上角常驻：? 帮助 + 右面板折叠钮。

### 4.2 侧栏（Sidebar 重构）🔴

自上而下按 ZCode 结构：
1. 顶部：红绿灯区（系统）+ 折叠钮 + 前进/后退
2. **操作组**（行式大导航，20px 图标+14px 文字）：新建任务(⌘N 徽标)、搜索(⌘K)、自动化、插件市场
3. **分组 tab 胶囊**：`# 分组 | 📁 项目`（选中白底浮起）+ 右侧钉住/清理小图标 → 替代现有三视图图标组（三视图保留在此切换器语义下）
4. 项目树：分组标题灰字「项目」→ 项目行（📁+名）→ 会话行（缩进 + 右对齐灰相对时间）——替代现在平铺会话列表
5. 「任务」分组：免项目聊天归此组
6. 底部用户条：圆形头像（Logo）+ 用户名 + Lite 徽章 + 手机图标 + 设置齿轮 → 点击弹出**用户菜单**（见 4.9）；组织登录后此条显示组织态，登录入口收进菜单
- 视觉：去边框、行高 36px、hover 圆角 8px、选中底 `--bg-active`

### 4.3 主界面欢迎页（新增 WelcomeView）🔴

- 居中：Logo 线稿版（SVG 描边化处理或直接图形）+ 问候语大标题（时间感知：「早上好/中午好/晚上好」+ 轻文案）+ 通知/额度信息条（预留组织配额接入点：额度百分比+进度，未登录隐藏）+ 项目选择浮起输入卡 + 四个**快捷 chips**（周报总结/报错修复/PPT 制作/闲时任务→映射 LaboFlow 场景：会议纪要整理/数据快查/调研启动/定时任务）
- 输入卡三行结构（见 1.3）；发送钮=圆形，空输入灰、有内容黑

### 4.4 会话视图（ChatView 改造）🟠

- 顶部条保留（权限模式标/辅助对话/撤销/分叉/导出），但全部改幽灵图标钮
- 消息流：用户气泡黑底白字（现 accent teal→黑）；工具卡=白卡圆角 12；时间线节点密度维持
- **审批卡**：白卡+左上语义图标（橙）+ 标题/目标两行 + diff 区（inset 底）+ 按钮组=主黑「允许」+ 次按钮其余四档
- 计划卡/Goal 卡：白卡+图标+步骤列表+黑主按钮
- 划选浮条/编辑重发/子Agent 卡/产物卡：统一白卡形制

### 4.5 权限模式选择器（重做）🔴

- 触发钮：`🛡 完全访问 ▾`——橙图标+橙字+浅橙底胶囊（选中模式唯一色彩点）
- 下拉：白浮层四项，每项=线性图标+**粗标题+灰说明**（「改文件前先问我。」等 ZCode 文案风格）+ 选中 ✓ + 浅灰底
- 组织策略下限生效时：按钮旁灰字小标「组织策略」+ tooltip（保留现有 D 注入逻辑，前端仅展示变化）
- **废除四色模式体系**（MODE_STRICTNESS 色彩映射删除；`--lf-mode-*` 语义 token 收敛为单 perm-color）。涉及 PRD 附录 C5 色彩编码修订 → 文档同步项

### 4.6 设置中心（对话框 → 全屏页 + 左导航）🔴 结构性

- 新 `SettingsPage`（全屏视图）：左导航（分组+行，ZCode 三组）+ 右内容（大标题+说明行+内容卡）
- 导航映射（LaboFlow 12 分区 → ZCode 三组）：
  - **基础设置**：常规 / 外观 / 模型设置 / 浏览器与计算机 / 快捷键
  - **Agent 能力**：记忆 / 专家与子智能体 / 插件 / MCP 服务器 / 技能 / 命令 / 钩子(占位) / 语音
  - **数据与统计**：使用统计 / 组织（登录态/工作区） / 关于
- 每页头部：大标题 + 一句说明 + 右上刷新（如模型页）
- 原 SettingsDialog 拆解迁移；所有「未实现占位页」改 ZCode 虚线空态形制

### 4.7 模型设置页（重做）🔴

- 左栏：供应商列表卡（分组「内置供应商」/「自定义」，行=图标+名+连接状态绿点，选中描边高亮）+ `+ 添加供应商`
- 右栏：详情卡（Logo+名+「已启用」绿徽章+连接方式下拉；**套餐/余额卡**：进度条+百分比+额度数字+过期时间——组织网关渠道显示配额余量，BYOM 渠道此卡隐藏）；**模型列表行**：等宽模型名 + 标签胶囊（视觉/1M 等能力标）+ 快捷键钮 + 编辑铅笔
- 前后端联动：channels API 增加「余额/套餐」可选字段（网关渠道从 bootstrap policyFloor/配额余量接口取；BYOM 留空隐藏）

### 4.8 管理页统一模板（技能/MCP/子智能体(专家)/插件 四页）🔴

统一 `ManagedListPage` 模板，四页共用：
1. 头部行：作用域下拉（用户/项目）+ `技能 N` 计数 + 大圆角搜索框
2. 「已安装 N」行 + ···/刷新/`+ 新建`（黑主钮）
3. 空态=虚线卡（标题+说明+黑主钮+白次钮「导入」）
4. 分组卡片列表：类型化方形图标（+状态点）+ 名称（粗）+ 单行描述/状态 + 标签胶囊（全部工具/N 个工具/默认/来源）+ 右侧开关或下拉（继承默认）
5. 各页数据源映射：技能→skills、MCP→mcp_servers（状态点=connecting/ok/failed）、专家/子智能体→experts（含 general/explore 内置组）、插件→plugins（三分 tab：插件/MCP/技能计数切换）
- 前后端联动：列表 API 增加 `scope` 过滤参数与分组元数据；插件页需要三类计数

### 4.9 用户菜单（新增）🟠

- 点侧栏用户条 → 底部向上弹出白卡菜单：分组1 界面语言▸/界面主题▸/界面缩放▸（子菜单或就地循环）；分组2 使用统计（跳全屏页）/升级（预留组织套餐）；分组3 断开连接（组织登出）
- 组织登录态时菜单并入组织信息（org 名/角色）与「断开连接」

### 4.10 用量统计页（全屏页重做）🟠

- 头部：大标题+「应用用量/个人套餐」分段
- 五指标卡行（累计 Token/峰值/最长会话时长/当前连续/最长连续）
- Token 活动热力图（按月分列格子+色阶图例+每日/每周/累计切换）
- 时间范围分段（近7日/近30日）+ 每日平滑趋势图（按模型分色+图例）+ 模型用量排行
- 前后端联动：server usage 聚合扩展（峰值/最长会话时长/按模型日序列——`GET /api/usage/mine` 已具备日×模型粒度，补端点聚合字段）；客户端 UsageService 补对应聚合函数

### 4.11 其余套用统一模板的区域 🟡

- 右栏五面板（子Agent/产物/浏览器/专家/组织）：行卡片统一（40px 图标块+名称+说明+右侧操作），去自造样式
- 命令中心/斜杠面板：白浮层 12px 圆角+分组+搜索框形制
- 空态全部替换虚线卡形制（欢迎页/列表/面板通通一致）
- admin-console：同步 token v3（低成本变量替换），形制不变

## 七、明确不做 / 裁决说明

1. **不引入路由库/组件库**：维持 Zustand state + Radix 现状，全屏页用视图 state 实现。
2. **权限模式从四色收敛为单橙语义**：ZCode 基准优先（用户明确指示）；行为语义（四档/五档审批/策略下限）不变，仅视觉表达变化；PRD 附录 C5 同步修订。
3. **ZCode 独有且 LaboFlow 无对应后端的能力**（索引库、电脑控制、升级套餐商业化）→ 导航占位虚线卡（「即将支持」），不造假数据。
4. **不拷贝 ZCode 任何美术资产**（Logo 线稿、图标 path、文案）：以同形制自绘实现（沿用既定 D-D4 合规边界）；问候语文案自写。
5. LaboFlow 特有功能（产物工作台/组织协作/专家团队/研究/消息中心）无 ZCode 对应页 → 全部套用本计划书的统一模板与 token，不新造形制。
