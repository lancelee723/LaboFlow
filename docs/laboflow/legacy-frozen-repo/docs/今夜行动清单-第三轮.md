## Wave 1：Composer 触发器补全（V4+V5，约 1.5h）

**SPEC 增补（§4.11 CommandService / 输入解析层）**：
- 输入框 `/(cmdQuery)$` 触发命令弹窗：数据源 `CommandService.list()`（内置 /goal /compact /side /research + 自定义 + 导入），两分组「命令 / 技能」（技能=已启用 SKILL.md，走 skills:list）；↑↓ 导航、Enter/Tab 插入 `/name `、Esc 关闭。
- 输入框 `\$(skillQuery)$` 触发技能弹窗：数据源同上技能组；选中插入 `$name `（后端 expandInvocations 展开）。
- ＋菜单四项全部改为**调出对应弹窗**而非插字符；技能项文案改「使用 $ 选择技能」。

**验收**：
1. 输 `/go` → 弹窗出现 /goal /goal 等，Enter 插入
2. 输 `$sl` → 弹窗出现 slides 技能，选中插入 `$slides `
3. ＋菜单点「使用 / 选择命令」→ 命令弹窗直接打开
4. 单测：触发正则（含中文后缀、行首/空格后）+ 插入格式

## Wave 4：MCP OAuth 接线（FR-C-42 收口，约 1h）

**SPEC（§4.4 McpBridge）**：MCP 分区服务器卡片支持 `oauth` 类型：配置 `authUrl/tokenUrl/clientId/scopes` → 「授权」按钮 → 系统浏览器打开授权页 → 回调 `laboflow-mcp://callback?code=` 捕获（protocol handler 注册）→ `exchangeOAuthCode`（PKCE）→ access_token 写 safeStorage → 连接时注入 `Authorization: Bearer`。
- 验收：mock token endpoint 全流程单测（URL 构建/code 交换/凭据加密存储/重连携带）；token 过期重走授权。

## Wave 5：userConfig 注入（FR-C-43 收口，约 1h）

**SPEC（§4.6 插件安装）**：安装预览检出清单 userConfig.required → 安装确认前弹配置表单（type=password 打码）→ `applyUserConfig` 注入配置模板 `${user_config.*}` → 落盘；`maskSensitive` 回显。
- 验收：含 required userConfig 的插件（fixture）安装后 MCP/命令文件中值已注入；缺字段阻断；sensitive 只显示尾 2 位。

## Wave 6：Hooks 完整协议（FR-C-47，约 2h）

**SPEC（§4.17 HooksService 全量）**：7 事件（PreToolUse/PostToolUse/UserPromptSubmit/SessionStart/SessionEnd/Stop/Notification）× matcher（精确列表/JS 正则）× command 执行器；stdin JSON（camelCase+snake_case 双键）、退出码 0/2/其他、stdout JSON（continue/denyReason/additionalContext）、Stop block ≤3；会话启动快照；设置「钩子」分区（事件列表+启停+日志查看）。
- 验收：契约测试集（每事件样例对 + 退出码矩阵 + matcher 匹配 + deny>ask>allow 聚合）。

## Wave 7：闲时任务 + 圆桌 + 组织专家库（FR-C-46/16/17，约 1.5h）
