## Wave 4：Hooks 全事件打通 + 设置「钩子」分区（约 3h，本轮最大项）
- **接线**（HooksService 已有决策引擎，缺的是触发点）：
  - `UserPromptSubmit`：AgentService.prompt 入口（拦截层之后、引擎之前）——block 则发系统消息拒绝发送；additionalContext 追加进 prompt。
  - `PreToolUse`：挂入权限门同一回调（EngineHost `__gate` 反向请求主进程处理点）——block 则拒绝该次工具调用（理由回传引擎）。
  - `PostToolUse`：`onDriverEvent` `tool_end` 分支。
  - `Stop`：run 正常收尾处——block 且 <3 次则自动 followUp("继续")（复用 MAX_STOP_BLOCKS）。
  - `SessionStart/SessionEnd`：createSession/dispose。
  - `Notification`：notificationService.emit 处同触发。
- **配置约定**：`<dataDir>/hooks.json`（`{ event, matcher?, command, enabled? }[]`），服务启动加载 + 手动重载 IPC。
- **UI**：设置新增「钩子」分区：配置文件路径 + 重载按钮 + 钩子列表（事件/匹配器/启停开关）+ 空态引导文案。
- 验收：契约测试（临时 hooks.json：UserPromptSubmit 追加上下文→mock 回复含该内容；PreToolUse 退出码 2→工具被拒；Stop block→自动续跑一次）；实机截图钩子分区。
