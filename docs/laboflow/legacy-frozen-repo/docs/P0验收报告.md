### T0.3 Pi 内嵌技术验证（Spike）+ ADR — ✅ 通过

## 四、边界说明与遗留

1. **平台验证边界**：本机为 macOS arm64——mac 打包+运行已实测；Windows/Linux 包由 CI matrix 构建产件覆盖（首次 push 打 tag 即可验证），未在本机实测。electron-builder 已对 pnpm 10 的平台可选依赖收集方式给出提示，CI 首跑时如缺 clipboard 等可选原生件按提示补 optionalDependencies 即可（不影响主链路）。
2. **视觉验证方式**：自动化截图（screencapture）+ 真实键盘事件驱动（辅助功能授权后）；macOS 键盘事件对长中文串有丢字符现象（osascript CGEvent 已知限制），不影响应用本身——剪贴板粘贴路线验证通过。
3. **更新源**：当前为占位桶（updates.laboflow.dev），域名未解析时 updater 静默失败（已捕获）；生产替换为组织自托管源即可。
4. **渲染性能预算**（SPEC §9：冷启动 ≤3s 等）留到 M1 以自动化计时固化；当前人工观察启动流畅。
5. 应用图标使用 Electron 默认图标（打包日志提示），品牌图标在 M1 设计交付时补齐。
6. 代码签名/公证按计划在 M1 接入（当前 identity: null 出未签名包）。
