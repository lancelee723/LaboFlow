# P5-UI LaboFlow UI 全面移植（SztuCode 基准）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在主进程与 IPC 契约零改动的前提下，把 LaboFlow Desktop renderer 全面重写为 SztuCode 桌面端的布局、信息架构、组件形态与视觉语言。

**Architecture:** 就地重写 renderer 组件层（方案 A）。packages/ui 重写为 tokens v4（SztuCode appearance.css 为真相源，`data-*` 属性驱动主题）；SztuCode 的核心 CSS 近乎原样移植为 `styles/sztu/*.css`（保真优先，Tailwind 只补缝隙）；React 组件按 shell/composer/timeline/inspector/pages/dialogs/ui 七组分文件重建；纯逻辑（turn 分组、工具分桶、格式化）抽为 `lib/sztu/*` 可测函数。

**Tech Stack:** Electron 44（不动）/ React 18 / Tailwind v4（工具类引擎）/ Radix（弹层原语）/ lucide-react / highlight.js（新增）/ Vitest 3（新增 jsdom + @testing-library/react 做 renderer 测试）。

**Spec:** `docs/specs/2026-09-09-sztucode-ui-port-design.md`（唯一设计真相源，本计划按其 §编号论证）。**移植参照物（normative source）：`/Users/lance/SztuCode/desktop/src/`**（App.vue、13 个 CSS 文件、components/*）。凡「移植自」均指该目录下文件；像素与数值冲突时以 SztuCode 源文件为准，语义冲突时以 spec 为准。

## Global Constraints

- **回归红线：`apps/desktop/src/main/**`、`apps/desktop/src/preload/**`、`packages/shared/**` 不允许出现任何 diff**（每 task 提交前 `git status` 核查）。

- data-testid 全量保留旧 testid（验收链），新组件按 `lf-<域>-<元素>` 补齐。
- 提交纪律：每 task 1-3 个 commit，格式 `p5ui(<域>): <内容>`；主进程零 diff 核查写入 commit 前的验证步骤。
- MIT 归属：M5 前在根目录加 `NOTICE.md`，含 `SztuCode Contributors`（MIT, github.com/rojim666/SztuCode）归属行。
