# LaboFlow bug和新增需求反馈清单

1.Logo在暗黑模式下，因为中间的“LaboFlow”的文字是黑色，会导致黑色文字与背景融为一体，让用户看不出来，解决办法有两个：A）制作一个专用于暗黑模式的Logo，将黑色文字改为白色；B）不改动文字，但给Logo套一个白色的背景，即便在黑暗模式下也是白色背景+渐变色块+黑色文字。对应问题图：'/Users/lance/LaboFlow Desktop/参考文件/bug反馈1.png'

2.初次打开LaboFlow，若打开时是在浅色主题下，打开“搜索”或其他出现悬浮式菜单的页面， 会出现悬浮菜单背景丢失（显示为半透明）的情况，导致悬浮菜单与背后的内容重叠，影响使用。但经测试，一旦切换黑暗模式，或者打开时就是黑暗模式，然后再切回浅色主题，则悬浮菜单会正常显示背景。对应问题图：'/Users/lance/LaboFlow Desktop/参考文件/bug反馈2.png'

3.左侧工作区最下方有一条横线，横线下方有“引擎: **Pi 引擎**”的字样，横线及文字均可以删除。对应问题图：'/Users/lance/LaboFlow Desktop/参考文件/bug反馈3.png'

4.左侧工作区的“分组”、“项目”和“时间线”，现在做成了类似滑动开关的效果，但由于三个选项本身没有背景或阴影，导致用户不好分辨，我建议对标ZCode的做法：A）只显示“分组”和“项目”两个选项，并将两个选项都放在一个胶囊状的背景框里面，用浅灰色（黑暗模式下可以是深灰色）背景将这两个选项“高亮”，当用户选择某个选项时，选中的选项还有一个白色（浅色主题）或黑色（暗色主题）的胶囊框起来；B）像ZCode那样在“分组”、“项目”的右侧做2个图标：一个是“筛选和排序”，点开后显示“视图”和“排序方式”两种分类方法，“视图分类”包括：”项目“和”时间线“，排序方式包括“更新时间”（即最后一轮对话的时间）和“创建时间”（即首轮对话时间）

5.左侧工作区中的会话列表，没有删除或“归档”的按钮，我建议做成“归档”机制：当用户将鼠标指针移动到会话标题上时，最右侧显示一个归档icon，点击之后该任务会话就被放置在对应工作区的”档案库“里面，而不是直接删除；然后在”设置“菜单中增加一个“归档记录”，可以按项目或时间排列用户“归档”的会话，在这里用户才能真正地删除某个会话记录历史。参考图片是'/Users/lance/LaboFlow Desktop/参考文件/Cortex参考图3.png'

6.点击“自动化”按钮，会直接跳到“设置”菜单的”通用“选项，而不是“自动化”，而且我怀疑自动化功能还没有做

7.中间工作区的“权限”按钮，也就是提示用户权限的那个按钮，存在与2一样的在浅色主题下背景半透明问题，对应问题图：'/Users/lance/LaboFlow Desktop/参考文件/bug反馈4.png'；

8.中间工作区的“思考”按钮，在靠近“权限”按钮那边有一个大脑图标+思考文字+阴影圆形图标的区域，点击这个区域可以调整LLM的思考等级，但右侧靠近对话框“发送”按钮的地方又一个“等级“的下拉菜单选项，这个地方点按之后也可以变动LLM的思考等级，而且这里的下拉菜单没有做，只有点按之后的有动作变化。我建议只保留最右侧的这个区域即可，要求是用大脑图标+下拉菜单即可。另外，你要核查一下对应的后端，有没有真的让LLM的思考深度发生变化，而不是做了个”安慰剂“按钮

9.中间工作区顶部有一个Banner，显示授权等级、条目数 0撤销本轮文件分叉md等内容，这个好像没什么用吧？可以删除。对应问题图：'/Users/lance/LaboFlow Desktop/参考文件/bug反馈5.png'；
