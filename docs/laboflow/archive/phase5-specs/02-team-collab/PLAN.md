## 批次 A：服务端空间模型（可与 Phase 4 客户端并行）

- **T52.1 空间与文档树模型**（M）：`apps/server` 新增 spaces 模块：`spaces`（复用/扩展 workspaces 表：加 `archived_at`）、`space_nodes`（文档树：id/spaceId/parentId/type `folder|md|csv|html|file`/name/sort_key/路径）、`space_docs`（MD/CSV/HTML 正文与版本）、文件类节点复用既有交付物卷存储；节点 CRUD API + 回收站（软删 30 天）。— 验收：树操作集成测试（嵌套/移动/环路防护/删除恢复）；NFR-TC2 规模用例。
- **T52.2 权限四档与邀请**（M）：权限矩阵扩展到空间+节点（node 级覆盖 space 级：无权限档=显式 deny）；邀请链接（token 一次性/有效期/可申请-审批流）、组织内外协作范围管控（组织设置项 + 分享面板锁定逻辑）；审计事件（读/写/授权）。— 验收：PRD §3.2 权限矩阵逐条集成测试；组织外账号链接加入被拒（仅组织内模式）；越权渗透用例（含 Agent 身份代读）全拒。
- **T52.3 文档同步协议扩展**（M）：既有 WS 推流帧扩展：`doc.updated`（MD/CSV 内容版本通告）、`comment.*`、`revision.*`、`presence.*`（HTML CRDT awareness）、Yjs 二进制 update 帧（binary）；条目序号机制沿用（`shared_session_entries` 模式平移到 `space_events` 表）。— 验收：3 客户端断线重连增量同步不丢事件；帧契约测试。

## 批次 B：客户端空间与资料库（M-TC1）

- **T52.4 团队空间客户端骨架**（L）：工作区页扩展为「团队空间」：左栏空间列表 + 文档树（拖拽/右键菜单/回收站）；右侧内容区按节点类型路由（MD/CSV/HTML/文件预览）；离线只读降级横幅。— 验收：FR-TC-01/03/20；树操作与拖拽 E2E；缓存浏览可用。
- **T52.5 放入资料四方式**（M）：新建 MD/CSV/HTML；上传（分片/进度/≤200MB）；**剪藏网页**（browser-view 加载 URL → Readability 正文提取 → 存 MD/HTML + 原链与时间元数据）；Agent 直落（会话产物「存入空间」动作 + 任务指令「生成到空间 X」的输出重定向，联动交付物 source='session' 既有通道）。— 验收：FR-TC-02/18 直落部分；剪藏 3 个真实站点正文完整。
- **T52.6 分享面板与成员管理 UI**（M）：邀请与管理成员面板（成员列表/改档/移除/复制链接/二维码）、链接访问方式设定、协作范围展示。— 验收：FR-TC-05/06。

**Gate M-TC1**：FR-TC-01~07 验收；权限矩阵与邀请链路 E2E；上传/剪藏/新建全通；既有 Phase 4 E2E 不回归。

## 批次 C：MD 审阅模式（M-TC2，核心体验）

- **T52.7 MD 编辑器**（M）：所见所得 MD 编辑（标题/列表/表格/代码块/图片），保存=版本化提交（乐观锁：版本冲突提示刷新）；正文与评论侧栏双栏布局。— 验收：MD 往返无损（schema 快照测试）；版本历史可查可回滚（节点版本表）。
- **T52.8 划词评论**（M）：选区→锚定（SPEC §3.3 锚定模型）→评论线程（回复/@/状态流转）；锚定失效检测与降级展示；未读评论徽标；评论与正文位置联动滚动。— 验收：FR-TC-08；并发编辑下锚定冲突率测试（NFR-TC4）；3 人评论线程 E2E。
- **T52.9 AI 修订建议管线**（L，核心）：划词+修改要求 → 主进程 RevisionService：拉取文档上下文 → one-shot LLM 产出结构化建议（原选区/改后文本/理由/锚定）→ 服务端存 `revision_suggestions`（待确认）；侧栏「原文/改后」对照卡 + 逐条接受（按锚定串行合并，冲突显式提示）/拒绝/批量接受；接受写入走文档版本链；撤销栈统一（AI 写入与手动编辑混合回退）。— 验收：FR-TC-09/11；接受后正文与建议一致（往返断言）；10 条并发建议批量接受冲突处理正确；撤销/重做混合栈 E2E。
- **T52.10 按评论修订**（M）：聚合全部打开状态评论 + 正文上下文 → 产出修订建议集（复用 T52.9 管线，多锚定）；完成后通知评论者（消息中心联动）。— 验收：FR-TC-10；含 @提及的评论上下文正确进入 prompt。
- **T52.11 Agent 空间引用与写回**（M）：composer 文件选择器「团队空间」源（有权文档树 + 分块拉取）；Agent 修改 MD 默认产出修订建议（RevisionService 以 Agent 身份调用，标注 AI 来源）；组织策略开关（直接写需审计）。— 验收：FR-TC-17/18；Agent 越权访问被拒且错误信息可读；AI 修订建议标注与人工区分。

**Gate M-TC2**：FR-TC-08~11/17~18 验收；「划词→AI 建议→逐条接受→撤销」全链路 E2E 三平台；Agent 权限一致读取渗透测试通过。

## 批次 D：HTML 协同与 CSV（M-TC3）

- **T52.12 HTML 编辑器与划词直改**（L）：块结构编辑器（标题/段落/列表/表格/图片/图表块）；划词→AI 指令→就地应用（加载态→高亮改动→可撤销）；预览/编辑切换、导出独立 HTML。— 验收：FR-TC-12/14；AI 改动高亮与撤销正确。
- **T52.13 CRDT 多人同时编辑**（L）：Yjs 文档模型 + 服务端 y-websocket provider（`/yjs/:docId`，JWT 鉴权 + 成员校验）+ presence（awareness 光标/选区/昵称色）；离线重连自动合并。— 验收：FR-TC-13；10 客户端并发编辑收敛性测试（自动化：随机操作流 10k 步收敛一致）；断网 5 分钟重连无丢字。
- **T52.14 CSV 编辑器**（M）：表格编辑（单元格/行列/排序/筛选）、UTF-8 严格往返、Agent 读写上下文；图表预览（C 级，可后移）。— 验收：FR-TC-15；往返不变性测试（含逗号/引号/换行/BOM 用例）。
- **T52.15 空间活动流与全文检索**（S）：活动流页（审计事件渲染）；标题+MD/CSV 正文检索（服务端 tsquery/like 分级）。— 验收：FR-TC-19/21。

**Gate TC（模块出口）**：见 PRD §6；另加：CRDT 收敛性自动化测试入库；服务端安全自查（上传扫描/权限矩阵/注入）报告。

## 里程碑总览

```
M-TC1（约 4 周）→ 空间/树/权限/邀请/放入资料            [批次 A+B]
M-TC2（约 4 周）→ MD 审阅模式（评论+修订建议+Agent 写回） [批次 C] ← 核心体验
M-TC3（约 3–4 周）→ HTML CRDT 协同 + CSV + 检索          [批次 D] → Gate TC
```

## 风险与对策

| 风险 | 对策 |
|---|---|
| CRDT 引入新技术栈（Yjs）工程风险 | 隔离在 T52.13 单任务；M-TC2 不依赖它（MD 是服务端权威）；做不通可降级「段落锁」保底（预案见 SPEC §3.5） |
| 修订建议锚定在真实编辑流中漂移 | 锚定=段落序号+文本摘要双校验；冲突显式提示；NFR-TC4 指标门 |
| 服务端表面积扩大（审计/检索/存储） | 批次 A 先行且与 Phase 4 打磨并行；规模用例前置（NFR-TC2） |
| 与 Phase 4 共享会话的概念混淆 | 文档树/评论/修订全部走新 `space_*` 表，不与 `shared_sessions` 复用行；UI 上「会话」与「文档」分区明确 |
