# 调研底稿：飞书 / 企业微信 / 微信机器人官方 API 概览

- 日期：2026-09-11（官方开发文档核验）
- 用途：模块 03（远程指挥）、模块 04（IM 通道）的通道可行性裁决与 SPEC 依据
- 场景约束：桌面应用常在 NAT 后（无公网 IP），需**收消息**（下指令）+**发回复**（文本与文件）

## 结论速览

| | 飞书自建应用 | 企微自建应用 | 企微智能机器人 | 企微群机器人 | 微信公众号 | QQ bot |
|---|---|---|---|---|---|---|
| 免公网收消息 | **✅ SDK WebSocket 长连接** | ❌（webhook 回调） | **✅ WSS 长连接** | ❌（只推不收） | ❌（webhook 回调） | ✅（WSS） |
| 发文件 | ✅ ≤30MB（file_key） | ✅ ≤20MB（media_id 3 天） | ✅ ≤20MB（分片上传） | ✅ ≤20MB | 素材/图文（间接） | ✅ |
| 回复窗口 | 无（5 QPS/用户） | 无 | 24h（流式 10min 内） | n/a | **48h 内 5 条**（客服消息） | 会话制 |
| 鉴权 | app_id/secret → tenant_access_token | corpid/secret → access_token | BotID+Secret（连接鉴权） | webhook key | appid/secret → access_token | AppID/Secret |

**推荐实现顺序**：飞书（WS 长连接，官方明确「无需公网 IP/内网穿透」）→ 企微智能机器人（WSS）→ 微信公众号（经服务端中继）。微信个人号**无官方 bot API**，非官方协议（wechaty/padlocal 类）有封号与合规风险，明确不走。

## 1. 飞书开放平台（open.feishu.cn）

- **长连接（推荐）**：企业自建应用 + 官方 SDK（Go/Python/Java/Node ≥1.24.0）出站连接；文档明示免公网 IP/内网穿透。限制：自建应用专用；单应用 ≤50 连接；事件需 3s 内处理（超时会重推）；集群模式每事件只投一个连接；按 `message_id` 去重（非 event_id）。
- **Webhook 回调（备选）**：需公网 URL + challenge 验证 + Verification Token；v2.0 事件可选 Encrypt Key（AES 信封）；网络失败重试 3 次、超时重推至多 4 次（15s/5min/1h/6h）。
- **鉴权**：`tenant_access_token`（app_id+app_secret，2h 有效需缓存）；用户身份走 OAuth 授权码流（redirect URI 配置；新 token 为 JWT；**无设备码流**——Workbuddy 的 lark-cli 扫码属官方 CLI 能力，另案）。
- **收**：事件 `im.message.receive_v1`（message_id/chat_id/chat_type/message_type/content JSON/mentions/open_id）。
- **发**：`POST /open-apis/im/v1/messages?receive_id_type=open_id|chat_id`（text/post/image/file/audio/media/sticker/interactive）；回复优先 `POST /im/v1/messages/{message_id}/reply`；`uuid` 参数幂等。容量：文本 150KB、卡片 30KB。
- **文件**：图片 `im/v1/images`（≤10MB→image_key）；文件 `im/v1/files`（≤30MB；opus/mp4/pdf/doc/xls/ppt/stream→file_key）。
- **权限**：收 `im:message.p2p_msg:readonly` / `im:message.group_at_msg[:readonly]`（群@）/ `im:message.group_msg`（全量，敏感）；发任一 `im:message` / `im:message:send_as_bot` / `im:message:send`；上传 `im:resource[:upload]`。需开机器人能力 + 发布版本 + 可用范围覆盖。
- **限速**：发 5 QPS/用户、5 QPS/群（跨 bot 共享）、应用 50 QPS；上传 50 QPS。
- 文档：事件订阅概述 / 长连接接入 / im.message.receive_v1 / 发送消息 / 上传文件（open.feishu.cn server-docs）。

## 2. 企业微信（developer.work.weixin.qq.com）

**A. 自建应用（经典，需公网）**
- 回调：公网 URL + Token + EncodingAESKey（43 位）；GET echostr 验证（1s 内、明文）；POST 为 AES 加密 XML；5s 响应、3 次重试、不保证送达。
- 发：`POST /cgi-bin/message/send`（touser ≤1000/@all；text/markdown 2048B；image/voice/video/file 经 media_id；textcard/news/template_card 等）；无 24h 窗口。
- 素材：`/cgi-bin/media/upload`（图 10MB/语音 2MB AMR≤60s/视频 10MB/文件 20MB；media_id 3 天，企业内应用共享）。
- 鉴权：corpid+corpsecret → access_token（7200s，按 secret 缓存）。
- 限速：每成员每应用 30 条/分钟、1000 条/小时。**无 WebSocket 选项。**

**B. 智能机器人（2025 新，API 模式，官方 WSS——本产品主路线）**
- 管理后台 → 安全与管理 → 管理工具 → 智能机器人；内置 LLM 或 API 模式（自带模型/agent）。
- **长连接**：`wss://openws.work.weixin.qq.com`，BotID + Secret 鉴权（区别于 Token/AESKey）；官方 SDK `@wecom/aibot-node-sdk` / `wecom-aibot-python-sdk`；单连接（新订阅踢旧）；~30s ping；免公网免消息加密。Webhook 模式为备选（需公网）。
- 收：文本/混合/引用（单聊 + 群@机器人）；图片/语音/文件/视频**仅单聊**（文件/视频 ≤100MB）；语音以转写文本到达；媒体 URL 5 分钟过期、AES-256-CBC 加密；单用户并发在途消息 ≤3。
- 发：被动/流式 `stream` 分块（10min 内完成；平台最长 6min 刷新）；`markdown` ≤20480B；`template_card`；文件/图/语音/视频分片上传（init/chunk/finish；图/视频 10MB、语音 2MB、文件 20MB；3 天有效）；欢迎消息 5s 内；主动 `aibot_send_msg` 仅限用户已发过消息的会话；**回调后 24h 内可回复**。
- 限速：会话 30 条/分钟、1000 条/小时；上传 30/分钟、1000/小时。
- API 模式机器人可授予文档/MCP 工具（云文档读写 + 8 个 MCP 工具、7 天授权）。

**C. 群机器人 webhook**：只推不收。POST JSON（text/markdown 4096B/image base64 ≤2MB/news/file/voice/template_card；文件经 upload_media ≤20MB）；20 条/分钟。

## 3. 微信（官方可行路线 = 公众号）

- **个人微信号：官方无 bot 收发 API**（截至 2026-09 无开放计划；元宝仅经腾讯元器渠道触达）。wechaty/padlocal 等协议方案属非官方，封号风险，禁用。
- **公众号（唯一官方收发回路）**：
  - 接收：服务器配置 URL+Token（公网 80/443；echostr 验证；可选 AES EncodingASKey 模式）；XML 推送（文本/图片/语音/视频/位置/链接）；5s 响应、3 次重试、msgid 去重。
  - 回复：被动 XML（5s 内）或**客服消息 API**（`cgi-bin/message/custom/send`）——窗口规则：**用户发消息 → 48h 内 5 条；菜单/关注/扫码 → 1 分钟内 3 条**；超窗报 45015。类型：text/image/voice/video/music/news/msgmenu/wxcard 等（媒体需素材 media_id）。认证服务号才有客服 API；测试号（mp.weixin.qq.com sandbox）可全功能开发。
- **替代托管路线**：腾讯元器（yuanqi.tencent.com）可建 agent 并授权公众号——但 agent 大脑在元器侧，不符合「本机执行」诉求，仅作参考。
- **对 LaboFlow 的含义**：公众号回调必须公网 → **经 LaboFlow Server 中继**（组织部署天然可用；个人用测试号+内网穿透自行体验，产品内明示定位）。

## 4. QQ 官方 bot（参考段）

q.qq.com 注册 AppID/AppSecret；**WebSocket 网关**（取 wss 地址 → intents/心跳/resume）或 WebHook 双官方模式；群消息需 @机器人，支持 C2C 与频道；REST 发回复（文本/markdown/媒体上传）。免公网的官方长连接先例，架构参考价值大于本期范围。
